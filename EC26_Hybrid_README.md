EC26 Gameplay Mod v1.6 (Hybrid)
An all-in-one gameplay module for PES 2021 (via Sider) that brings together custom referee logic, dynamic match tempo, refined physics, and a realistic injury system.

Key Features
Referee Assembly Cave: Overhauls call strictness and foul logic for far more consistent refereeing.

Dynamic Match Tempo: Adapts game pace dynamically in real time without breaking responsiveness.

Physics & Handling Adjustments: Fine-tuned ball weight, dribble friction, stop force, shot power, sprint touches, and player reaction times.

Dynamic Injury System: Integrates randomized injury triggers and variable severity rolls during matches.
